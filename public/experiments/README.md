# Project Genesis 实验档案

此目录收录用户提供的原始附件副本：实验数据 CSV、实验图表 PNG、报告 Markdown、中文假说 DOCX 与各阶段 ZIP 项目包。压缩包保留原样。

完整可点击清单见站点根目录的 `experiments.html`。截至整理时共 63 个原始附件，约 38 MB。

## 主要材料

- `PROJECT_GENESIS_FINAL_REPORT.md`：综合结论、各模块状态与边界。
- `G4.6_report.md`、`G4.7_report.md`：模型者控制与盲观察者报告。
- `genesis21*` 至 `genesis25*`：异常检测、干预、分类与模型发现数据。
- `g47_*`：G4.7 盲测数据与图表（部分细节数据在原始 G4.7 ZIP 包内）。
- `project_genesis_*.zip`、`genesis*.zip`：不同迭代的源代码/配置/数据快照。
- `建模者神学假说.docx`：原始中文假说与 Genesis 模拟设计稿。

历史数据按原样归档，不代表所有实验已达到独立复现或同行评审标准。请结合对应报告中的方法与限制解读结果。
